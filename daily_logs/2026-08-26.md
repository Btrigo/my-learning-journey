## 🧠 What I Learned / Key Takeaways

* An ISO file and a bootable installation USB are not the same thing; the Media Creation Tool properly partitions and prepares the USB.
* A single physical USB can contain multiple partitions, which Windows may display as separate drives.
* UEFI is the modern replacement for the traditional BIOS and controls hardware initialization and operating-system startup.
* GRUB is Ubuntu’s bootloader, while the Windows installer will eventually install Windows Boot Manager.
* Intel Platform Trust Technology provides firmware-based TPM 2.0 without requiring a physical TPM module.
* CSM allows UEFI to imitate an older BIOS for legacy hardware and operating systems. Disabling it permits a fully modern UEFI installation.
* Storage controllers initialize connected drives so the firmware can detect them and locate an operating-system bootloader.
* Secure Boot checks the digital signature of startup software and blocks untrusted or modified bootloaders.
* Installing the default Secure Boot keys gives the firmware a database of trusted software signers.
* Secure Boot, TPM/PTT, and BitLocker perform different but complementary security functions.
