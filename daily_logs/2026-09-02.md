## 🧠 What I Learned / Key Takeaways

* My strongest interview story is that I combine real data-center experience, customer service, and current hands-on Windows troubleshooting.
* When troubleshooting, first determine the scope: one user, one device, one application, or an organization-wide issue.
* My Linux Wi-Fi issue likely involved driver or kernel compatibility with the wireless hardware, making Windows the more reliable choice for my main machine.
* Intel Platform Trust Technology provides firmware-based TPM 2.0 functionality for Windows 11.
* Disabling CSM configures the machine to boot through native UEFI instead of legacy BIOS compatibility.
* It is more precise to say I configured the system for native UEFI booting—not simply that “all hardware initializes using UEFI.”
* Microsoft Basic Display Adapter is Windows’ generic fallback display driver and may not provide complete DisplayPort or multi-monitor functionality.
* A print queue stores pending jobs, while the Print Spooler service manages jobs between applications, drivers, queues, and printers.
* Printer troubleshooting should follow the path from the application to the queue, spooler, driver, port, connection, and physical printer.
* For urgent conference-room issues, restoring the meeting through a workaround may come before completing root-cause analysis.
* In a law firm, support prioritization must consider deadlines, privileged documents, client communication, and attorney downtime.
* My Active Directory experience should be presented honestly as hands-on lab experience rather than production administration.
* OUs primarily organize objects for policy and delegation, while security groups primarily grant access to resources.

## 🛠 Commands / Tools Practiced

* `services.msc` — View and manage Windows services, including Print Spooler.
* `Get-Service Spooler` — Check the Print Spooler’s status.
* `Restart-Service Spooler` — Restart the Print Spooler in PowerShell.
* `net stop spooler` / `net start spooler` — Stop and start the spooler from Command Prompt.
* `gpupdate /force` — Request immediate Group Policy reapplication.
* `gpresult /r` — Review applied Group Policies.
* `whoami` / `whoami /groups` — Verify the current user and security-group memberships.
* `ping` — Test basic connectivity to a network printer or other device.
* `Test-NetConnection <IP> -Port 9100` — Test common raw TCP/IP printer connectivity.
* `Windows + P` — Select Duplicate, Extend, or another external-display mode.
* Device Manager — Identify missing, generic, or malfunctioning drivers.
* Windows display, sound, privacy, and Teams/Zoom device settings.
