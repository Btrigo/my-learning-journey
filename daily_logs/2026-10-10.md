## 🧠 What I Learned / Key Takeaways

- `input()` always returns text. Converting that text determines which numeric formats the program accepts.
- `ValueError` can occur when a conversion receives unsuitable text. `ZeroDivisionError` occurs when dividing by zero. Other exceptions exist; catch the specific failures you expect rather than assuming every error is a `ValueError`.
- `try` contains the operation that might fail; `except` handles a matching exception. A `try` statement needs an `except` or `finally`; ordinary code does not always need exception handling.
- `else` after `try` runs when the try block completes without an exception. Our retry loop can stop there after successful parsing.
- `Fraction(text)` can represent whole numbers, decimal text, and ordinary fraction text exactly. Splitting input at `/` and dividing `Fraction(numerator)` by `Fraction(denominator)` also supports decimal values on either side.
- A fraction with a zero denominator is undefined. The program should explain that and prompt again instead of crashing.
- `text` is a variable name we chose, not a special Python keyword.
- Functions let us give reusable jobs names. A parameter appears in the function definition; an argument is supplied in the call.
- `import random` makes the standard-library module available. `random.choice(["Heads", "Tails"])` returns one randomly selected list item.
- Passing `"coin"` supplies literal text. If the function immediately assigns a random result to its `coin` parameter, that incoming text is overwritten.
- `print()` displays a value; `return` sends a value back to the caller. A function without an explicit return value returns `None`.
- `print(main())` prints main’s return value. If main already prints and returns nothing explicitly, an extra `None` appears.
- Calling a function twice runs its body twice. Two coin-function calls make two choices; they can happen to produce the same result. A returned value that is neither saved nor printed is not displayed by a script.
- `random.choice` refers to the function itself. `random.choice([...])` calls it and produces a result. Either the function or its result can be passed as an argument, provided the receiving function uses it appropriately.
- `main` is a conventional function name. Python does not run it merely because it is named main; `main()` calls it.
- Python supplies `__name__` automatically. For a directly executed file it is `"__main__"`; for our imported `libraries.py` example it is `"libraries"`.
- `if __name__ == "__main__":` calls main only when the file runs directly. A plain `main()` at the bottom is fine for practice, but also runs when that module is first imported.
- Lists hold ordered items retrieved by position, such as `students[0]`. Dictionaries associate keys with values, such as `students["Draco"]`. A list of dictionaries supports `students[1]["house"]`.
