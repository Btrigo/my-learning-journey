## 🧠 What I Learned / Key Takeaways

### SSDLC Fundamentals
- SSDLC (Secure Software Development Life Cycle) extends the traditional SDLC by integrating security into every phase instead of treating it as a final step before deployment.
- The earlier vulnerabilities are discovered ("Shift Left"), the less expensive and disruptive they are to fix.

### Shift Left Security
- Security should begin during planning and design rather than after development.
- Catching vulnerabilities early reduces development costs, minimizes rework, and lowers organizational risk.

### Risk Assessment
- Every application has risks that should be identified before development begins.
- Risks should be prioritized based on likelihood and potential business impact so the most critical issues are addressed first.

### CIA Triad
- **Confidentiality** – Ensure only authorized users can access sensitive information.
- **Integrity** – Protect data from unauthorized modification or corruption.
- **Availability** – Ensure systems remain accessible and operational for legitimate users.

### Threat Modeling
- Learned how to think like an attacker before writing code.
- Studied the STRIDE threat modeling framework:
  - Spoofing
  - Tampering
  - Repudiation
  - Information Disclosure
  - Denial of Service
  - Elevation of Privilege

### Secure Coding
- Applications should never trust user input.
- Sensitive information such as passwords and API keys should never be stored in plaintext or hardcoded into applications.
- Input validation, parameterized queries, hashing, salting, and secrets management are essential secure coding practices.

### Security Testing
- Learned the purpose of several security testing methodologies:
  - Static Application Security Testing (SAST)
  - Dynamic Application Security Testing (DAST)
  - Interactive Application Security Testing (IAST)
  - Penetration Testing
  - Dependency and vulnerability scanning

### DevSecOps
- Security is everyone's responsibility—not just the security team's.
- Modern CI/CD pipelines automatically perform security scans before software is deployed.
- Security continues after deployment through monitoring, logging, and incident response.
