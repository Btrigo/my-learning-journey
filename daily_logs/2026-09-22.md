## 🧠 What I Learned / Key Takeaways

- Docker uses a client/server architecture: the Docker CLI communicates with the Docker Engine through the Docker API/socket.
- `docker ps` shows currently running containers, while `docker ps -a` also shows stopped containers.
- A Docker image is a reusable template, while a container is an instance created from that image.
- Containers only remain running while their main process is running. The `hello-world` container exits immediately after printing its message.
- Multiple containers can be created from the same Docker image.
- `docker rm` removes containers, while `docker rmi` removes images.
- Terraform is an Infrastructure as Code (IaC) tool that can define and manage AWS infrastructure using `.tf` configuration files.
- Terraform was installed inside WSL/Linux rather than separately in Windows so my development tooling remains together inside my Linux environment.
- `amd64` refers to the x86-64 architecture and does not mean that the computer must have an AMD processor; my Intel CPU also uses this architecture.
- GPG signing keys allow APT to verify trusted software repositories/packages before installation.
- APT repository configuration tells Ubuntu where software packages can be retrieved and which signing key should be trusted for that repository.
- `netsh wlan show interfaces` displays information about the current Windows Wi-Fi connection.
- `netsh wlan show networks mode=bssid` displays nearby Wi-Fi networks, BSSIDs, channels, bands, and signal levels.
- Help-desk troubleshooting should follow a systematic process: identify the problem, check the physical layer, verify configuration, isolate components, test software, implement the fix, verify, and document.
- Device onboarding commonly involves inventory/asset tracking, Windows provisioning, organizational identity/device management, security policies, applications, user access, testing, and documentation.
- VPC Peering allows two VPCs to communicate privately using private IP addresses without routing that traffic over the public internet.
- VPC Peering is useful when separate VPCs need direct private communication while maintaining network separation.
- VPC Peering is non-transitive; larger environments with many interconnected VPCs may use AWS Transit Gateway instead.
- CloudFront is AWS's Content Delivery Network (CDN).
- Route 53 provides DNS and traffic-routing functionality.
- S3 provides object storage and can store static website/application assets.
- CloudFront can cache/distribute content closer to users to reduce latency.
- Elastic Load Balancing distributes incoming traffic across compute resources.
- API Gateway provides a managed front door for APIs and can integrate with AWS services.
- EC2 provides virtual machines, while Lambda provides serverless function-based compute.
- ECS manages containerized workloads, and Fargate provides serverless compute for containers.
- EBS provides block storage commonly associated with individual compute instances, while EFS provides shared file storage.
- RDS/Aurora provide managed relational database options, while DynamoDB provides managed NoSQL/key-value storage.
- Secrets Manager provides managed storage for application secrets and credentials.
- SNS, SQS, EventBridge, and Step Functions are important services for asynchronous communication, messaging, events, and workflow orchestration.
