## 🧠 What I Learned / Key Takeaways
- Subnetting: how CIDR notation maps to binary, how to calculate address counts and ranges, and that AWS reserves 5 addresses per subnet (not the standard 2) — network, router, DNS, reserved, and broadcast
- Broadcast address: last address in a subnet (all host bits = 1), used for "ask everyone" traffic like ARP and DHCP discovery — reserved in AWS subnets but never actually used since VPCs don't support broadcast
- NACLs vs security groups: security groups are stateful, instance-level, allow-only; NACLs are stateless, subnet-level, support explicit deny, and evaluate in rule-number order
- Full gateway comparison: Internet Gateway (free, bidirectional), NAT Gateway (paid, outbound-only for private subnets), Gateway Endpoints (free, S3/DynamoDB only), Interface Endpoints (paid, everything else, requires security group config)
- Elastic IPs: static public IPs, free only while attached to a running resource, reattachable without DNS delay — used for NAT Gateways and failover scenarios, not typically needed per-EC2-instance behind a load balancer
- NAT Gateway mechanism in detail: rewrites private source IP to its own public Elastic IP, tracks the translation so only self-initiated outbound traffic gets a return path — same "who initiated it" logic as stateful security groups, different layer
- SSH key pairs: entirely an authentication mechanism (not authorization) — private key never leaves the local machine, it signs a challenge from the server; the public key (placed in the instance's authorized_keys file at boot) verifies that signature. No secret is ever transmitted, only proof of possession
