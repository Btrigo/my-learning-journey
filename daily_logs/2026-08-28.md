## 🧠 What I Learned / Key Takeaways

* A clean Windows installation may initially lack the manufacturer-specific drivers needed to use all hardware features.
* `Microsoft Basic Display Adapter` is a temporary generic driver. It provided basic video output but did not properly initialize the GTX 1660’s DisplayPort outputs.
* Installing the correct NVIDIA driver restored DisplayPort and dual-monitor support, proving the monitors, cable, GPU, and ports were functional.
* Hardware IDs can identify an unknown device:

  * `VEN_10DE` identifies NVIDIA.
  * `DEV_2184` identifies the GeForce GTX 1660.
  * `SUBSYS_...1458` identifies Gigabyte as the card manufacturer.
* Intel Platform Trust Technology provides firmware-based TPM 2.0 for Windows 11.
* Secure Boot verifies trusted boot software, while CSM provides compatibility with older legacy boot methods.
* Selecting the `UEFI:` version of the USB entry boots the Windows installer in modern UEFI mode.
* Windows detected the Intel Wireless-AC 9462, but the missing external antennas likely explain its inability to detect nearby networks reliably.
* Installing only the NVIDIA Graphics Driver avoided the optional NVIDIA App and unnecessary extras.
