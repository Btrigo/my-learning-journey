## 🧠 What I Learned / Key Takeaways
- Python is the programming language; the interpreter runs the code. VS Code is the editor used to write it.
- Functions perform tasks. Parameters are the input names in a function definition; arguments are the values supplied when calling it.
- Variables give names to values. The = operator assigns the result of the expression on the right to the name on the left.
- input() returns a string, even when the user enters digits. Use int() or float() to convert suitable text before doing arithmetic.
- The + operator adds numbers but concatenates strings: "1" + "2" produces "12".
- F-strings insert values into text, such as f"hello, {name}".
- print() separates multiple arguments with a space and ends output with a newline by default. sep and end customize these behaviors.
- String methods include strip(), capitalize(), title(), and split(). strip() removes outer whitespace, not spaces in the middle.
- String methods return new values. Use reassignment to keep the result: name = name.strip().
- Methods can be chained, such as input("Name: ").strip().title().
- Comments begin with #. Pseudocode outlines the steps of a solution before implementing them.
- round() returns a rounded number. Formatting such as f"{total:.2f}" controls the displayed text without changing the original numeric value.
- Custom functions use def, a colon, and indentation. Defining a function does not execute its body.
- Default parameters allow a function to work when an argument is omitted, such as def hello(to="world"):.
- Variables assigned inside a function are normally local to it. Pass values as arguments when another function needs them.
- main() is a convention for organizing a program; it must be called explicitly.
- print() displays a value. return hands a value back to the caller so it can be saved or reused.
- Readability matters more than minimizing the number of lines. Errors are part of the learning process.
