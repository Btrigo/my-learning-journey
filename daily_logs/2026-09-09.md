## 🧠 What I Learned / Key Takeaways

* A device-driver date of June 21, 2006 in Device Manager is commonly a Windows placeholder and does not necessarily represent the motherboard’s actual BIOS date.
* The actual BIOS version and date can be checked through Windows System Information using `msinfo32`.
* A BIOS update is unlikely to fix this problem because the Wi-Fi adapter initializes, scans for networks, and connects to nearby signals.
* Detecting nearby hotspots and printers—but inconsistently detecting the home router—points toward a reception, antenna-path, or failing wireless-adapter problem.
* Since phones and laptops consistently detect the router, the Optimum modem, bridge mode, router placement, and router broadcast are unlikely to be causing the problem.
* Installing current Intel drivers, chipset updates, and Windows updates without improvement helped rule out several software-related causes.
* Changing the router’s channels, channel widths, security mode, and transmit power without improvement helped rule out router configuration.
* Wi-Fi 6 and Wi-Fi 6E cards are backward compatible with older Wi-Fi standards and can connect to 2.4 GHz and 5 GHz networks.
* The Intel AX210 uses standard PCIe/USB connectivity and is a safer replacement for this B360 system than CNVio-dependent AX201 or AX211 modules.
* A complete PCIe Wi-Fi card bypasses the onboard Intel AC 9462 and its existing antenna path.
* A movable antenna base can be positioned away from the metal computer case to improve reception.
* Matching the TP-Link brand of the Wi-Fi card and router is not required, but the Archer TXE75E is still a compatible and reliable choice.
* Wi-Fi communication uses the PCIe connection; the card’s internal USB cable is only required for Bluetooth.
