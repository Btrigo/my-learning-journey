## 🧠 What I Learned / Key Takeaways

- A PCIe Wi-Fi/Bluetooth card uses PCIe for Wi-Fi but an internal USB 2.0 connection for Bluetooth.
- Windows can recognize multiple Wi-Fi adapters simultaneously and labels them separately, such as `Wi-Fi` and `Wi-Fi 2`.
- The TP-Link TXE75E uses an Intel AX210 chipset, which Windows identifies as `Intel(R) Wi-Fi 6E AX210 160MHz`.
- Wi-Fi and Bluetooth portions of a wireless adapter can be managed separately in Windows.
- Device Manager is useful for distinguishing old and new hardware, checking driver status, reviewing device events, and diagnosing error codes.
- A yellow warning symbol in Device Manager indicates a device or driver problem; the old Bluetooth instance was reporting Code 31.
- The new AX210 successfully detects and connects to the 2.4 GHz network, confirming that the replacement Wi-Fi hardware is functioning.
- 5 GHz has shorter effective range and weaker wall penetration than 2.4 GHz, which can cause a weak network to appear and disappear.
- Moving the external antenna base and comparing reception with another device can help distinguish a Wi-Fi coverage problem from an adapter problem.
- Formatting the old drive as NTFS allows it to be repurposed as normal Windows storage.
