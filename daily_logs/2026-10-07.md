## 🧠 What I Learned / Key Takeaways
- A while loop repeats while its condition is True. Updating a counter or using break allows it to stop.
- A for loop visits items in a collection. In `for student in students`, Python assigns each successive item to the loop variable `student`.
- The loop variable’s name is my choice; Python follows the assignments and lookups I write.
- `range(3)` produces 0, 1, and 2, allowing three iterations. The stopping value is excluded.
- A list stores an ordered collection of items, accessed by position: `students[0]`.
- A dictionary stores key-value pairs, accessed by key: `student["name"]`.
- Lists can contain dictionaries. Each dictionary can represent one student with several related fields.
- Dictionary literals use braces and key-value pairs: `{"name": "Harry", "house": "Gryffindor"}`. I do not need to call dict().
- `name = "Brandon Trigo"` assigns a value to a variable. `"Brandon Trigo"` is not an argument in that assignment.
- A value becomes a function argument when passed into a function, such as `print("Brandon Trigo")`.
- In a dictionary, `"name"` is a key. Python retrieves its associated value when I write `student["name"]`.
- None represents an absent value and differs from the string `"None"`.
- A conditional can omit the patronus portion of the output when its value is None.
- print() ends with a newline by default. `end=""` keeps subsequent output on the same line.
- Nested loops can build a grid: the inner loop prints across a row, and the outer loop repeats rows.
- A print() after the inner loop can end each row. Indentation determines when that print() runs.
- Tracing each iteration helps explain output instead of guessing what the code does.
