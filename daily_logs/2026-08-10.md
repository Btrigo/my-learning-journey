## 🧠 What I Learned / Key Takeaways

- Microsoft Management Console (MMC) is a framework/container for Windows administrative tools called snap-ins.
- Snap-ins such as Computer Management and Event Viewer can be used to manage the local computer and, when permissions allow, remote computers.
- Remote Desktop Protocol (RDP) provides an interactive Windows session on another computer, while MMC can sometimes be used to manage specific components remotely without opening a full desktop session.
- Users can be granted Remote Desktop access without being made administrators, reinforcing the principle of least privilege.
- `msconfig` is mainly useful for troubleshooting startup and boot-related problems by controlling services, drivers, and startup behavior.
- Windows services are background components that provide system functionality and can be started, stopped, restarted, or configured.
- `ipconfig /all` is an important troubleshooting command because it exposes detailed network configuration such as IP address, subnet mask, gateway, DHCP, and DNS.
- Command Prompt and PowerShell are different ways of administering Windows, with PowerShell being much more powerful for automation and large-scale administration.
- PowerShell uses cmdlets and scripts to automate repetitive administrative tasks such as account provisioning.
- Action1 is not part of Active Directory. It is a separate endpoint/patch management platform used to centrally manage, patch, monitor, and deploy software to computers.
- Watching lab walkthroughs without understanding the underlying networking, Windows Server, DNS, DHCP, and AD concepts can make the steps difficult to follow.
- My learning should focus on understanding why a tool or configuration is being used, not just memorizing where someone clicks.
