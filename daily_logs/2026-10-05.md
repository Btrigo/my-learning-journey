## 🧠 What I Learned / Key Takeaways
- `input()` returns a string even when the user types numbers.
- `"5"` and `5` are different:
  - `"5"` is a `str`.
  - `5` is an `int`.
  - `5.0` is a `float`.
- Without numeric conversion:
  - `"5" + "6"` produces `"56"` because Python concatenates the strings.
- `int()` converts compatible values into integers.
- `float()` converts compatible values into floating-point numbers.
- `int` is technically a Python class/type, even though calling `int(...)` looks and behaves function-like when converting values.
- `type()` can be used to inspect what type of object a variable currently refers to.
- `round(number, 2)` produces a rounded numeric value.
- `f"{number:.2f}"` controls how a number is displayed and forces exactly two decimal places.
- Formatting examples:
  - `:.2f` → two decimal places.
  - `:.3f` → three decimal places.
  - `:,` → thousands separators.
  - `:,.2f` → thousands separators plus two decimal places.
- A `ValueError` can occur when Python cannot convert input into the requested numeric type, such as `float("sdfgs")`.
- A function is defined with `def`, but defining a function does NOT execute it.
- A function must be called before its body executes.
- Example:

    `def hello(to):`

  `to` is a parameter.

- Example:

    `hello("Brandon")`

  `"Brandon"` is an argument.
- A variable can also be supplied as an argument:

    `hello(name)`

- The caller's variable name and the function's parameter name do not have to match.
- Data can flow through a program like:

    User Input → Variable → Argument → Parameter → Function

- Started learning that `return` sends a value from a function back to whoever called that function.
- Bash scripts and Python programs share programming concepts such as variables, functions, input/output, and reusable logic, even though their syntax and primary purposes differ.
- For AWS/DevOps:
  - Bash is useful for automating repetitive CLI/workflow tasks.
  - A Bash script does not need functions if it is simple.
  - Functions become useful when a script becomes larger or contains reusable/logically separate operations.
  - Separate `.sh` files can also be used for different automation responsibilities.
  - CDK/Python should generally define what AWS infrastructure should exist.
  - Bash can automate the workflow around that IaC, such as testing, `cdk synth`, `cdk diff`, and `cdk deploy`.
