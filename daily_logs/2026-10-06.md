## 🧠 What I Learned / Key Takeaways
- Conditionals allow programs to make decisions using expressions that evaluate to True or False.
- Comparison operators:
  - > means greater than.
  - >= means greater than or equal to.
  - < means less than.
  - <= means less than or equal to.
  - == means equal to.
  - != means not equal to.
- A single = assigns a value; == compares values:
  - x = 5 stores 5 in x.
  - x == 5 checks whether x equals 5.
- if checks the first condition.
- elif checks another condition only when earlier conditions in the same chain were false.
- else handles the remaining cases without asking another question.
- Separate if statements can all execute. An if/elif/else chain selects at most one branch, then continues with the code after the chain.
- Colons and indentation are required for conditional blocks. Four spaces is the standard indentation convention.
- or combines conditions when at least one must be true.
- and combines conditions when both must be true.
- Python supports chained comparisons:
  - 90 <= score <= 100
  - This expresses the same range as score >= 90 and score <= 100.
- The order of conditions matters:
  - Checking score >= 90 before elif score >= 80 allows the second branch to handle scores from 80–89.
  - This simplified grading logic assumes valid scores between 0 and 100.
- Separate grade checks can produce incorrect results:
  - A score of 95 satisfies score >= 90 and score >= 80.
  - Separate if statements would print multiple grades.
  - An if/elif chain selects only the first matching grade.
- % is modulo: it returns the remainder after division.
  - 6 % 2 returns 0.
  - 7 % 2 returns 1.
  - n % 2 == 0 checks whether an integer is even.
- Functions can return Boolean values:
  - An is_even(n) function can use return n % 2 == 0.
  - The returned True or False can be used directly in a conditional.
- return sends a result back to the caller; print() displays output.
- A conditional expression can select a value in one line:
  - True if n % 2 == 0 else False
  - In this example, returning n % 2 == 0 directly is simpler.
- match/case provides another way to choose behavior based on a value.
  - case "Harry" | "Hermione" | "Ron": groups alternative matches.
  - case _: handles anything that did not match an earlier case.
- Good code should be correct, readable, and maintainable. Removing unnecessary checks helps, but shorter code should still be understandable.
