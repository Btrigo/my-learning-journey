## 🧠 What I Learned / Key Takeaways
- An ISO acts as installation media attached to the VM’s virtual DVD drive; Windows installs onto its virtual hard disk.
- A subnet mask of 255.255.240.0 is /20; the octet 240 is 11110000 in binary.
- A gateway can forward internet traffic without replying to ping. A timeout alone does not prove a device is down.
- DNS resolution and IP connectivity are separate functions. Comparing tests helps isolate the failure.
- A VM’s name in Hyper-V and its Windows hostname are separate settings.
- Standard users can download files and run some software without administrator rights.
- Local accounts belong to one computer; domain accounts are centrally managed through Active Directory.
- The Print Spooler manages print jobs; a print queue displays jobs for a particular printer.
- Administrative templates define settings displayed in Group Policy Editor. The policy target determines who receives those settings.
- The Non-Administrators local policy targets current and future standard users on the workstation.
- Our custom Edge restriction controls Edge downloads, not downloads through every application.
- Windows Server must have Active Directory Domain Services installed and be promoted before it becomes a domain controller.
